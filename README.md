Для сборки установите JDK 17 и выберите его в `JAVA_HOME` и в настройке Gradle JDK

компилятор Kotlin выполняется в том же процессе. В Windows для пути с кириллицей
JDK 17 нужен также для запуска wrapper: JDK 21 может передать пути в другой
кодировке. Альтернатива — распаковать проект в каталог с латинским путём.

## Запуск

- **IntelliJ IDEA / Android Studio:** открыть папку `Lab-1`, запустить `main` в `src/main/kotlin/pr1/Main.kt` (зелёная стрелка). Тесты — правый клик по `src/test/kotlin` → Run Tests.
- **Командная строка:** `gradlew run` — все демонстрации, `gradlew test` — тесты.
- **Kotlin Playground:** файл задачи можно вставить на https://play.kotlinlang.org, добавив `fun main() = demoTask1()` (или нужную `demo…` функцию).

Эмодзи в демонстрации разворота строки корректно отображаются только в консоли с UTF-8 (консоль IDE); в консоли Windows с кодировкой Cp1251 они видны как «?». Корректность разворота подтверждена тестом.
